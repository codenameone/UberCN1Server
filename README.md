## Building a new ride-hailing application? Start with Wayline

[Follow the Wayline tutorial](https://www.codenameone.com/blog/create-an-uber-clone-in-1-minute/).

Wayline includes rider and driver workflows, an administration console and a Java backend, with shared API contracts, live tracking and payment workflows. Its application source is free under MIT-0 for commercial use and customization.

[Get the source](https://github.com/codenameone/CodenameOne/tree/master/scripts/wayline) · [User’s guide](https://www.codenameone.com/developer-guide/wayline-users-guide/) · [Implementor’s guide](https://www.codenameone.com/developer-guide/wayline-implementors-guide/)

This repository accompanies the original Uber Clone book and course and remains available for those lessons. Wayline uses a different architecture. Live deployment requires provider configuration and validation; its Stripe integration has not been tested against a Stripe account.
